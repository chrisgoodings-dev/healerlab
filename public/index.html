        WHY THIS RECOMMENDATION?

        Explainable, not magical.

        HealerLab ranks opportunities using the character's actual dungeon scores and equipment. It does not claim to simulate healing throughput.

        THE PROJECT

        Built as a decision-support tool, not another profile page.

        01

        Retrieve

        A server-side endpoint requests public character data from Raider.IO.

        02

        Normalise

        Raw API responses are converted into a small internal character model.

        03

        Analyse

        JavaScript ranks score and gear opportunities using transparent heuristics.

        04

        Explain

        The interface shows why an activity was prioritised instead of presenting a black-box score.
